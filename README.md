# java-lotto-precourse
# 기능 목록

## 기능

### 입력
- 로또 구입 금액 입력 기능
```
구입금액을 입력해 주세요.
8000
```

- 구입 금액에 해당하는 만큼 로또 발행
    - 로또 1장 가격은 1000원이다.
    - 1000원 단위로 나누어 떨어지지않은 경우 예외처리


- 당첨 번호와 보너스 번호 입력 기능
    - 당첨 번호는 쉼표를 기준으로 구분
    - 그 후 보너스 번호 입력
```
당첨 번호를 입력해 주세요.
1,2,3,4,5,6

보너스 번호를 입력해 주세요.
7

```


- 번호 발매 기능
    - 로또 번호는 1~45이다
    - 중복되지 않는 6개의 숫자를 뽑는다

- 당첨 번호 추첨 기능
    - 중복되지 않는 숫자 6개와 보너스 번호 1개를 뽑는다.

- 당첨 기준, 금액 판단 기능
    - 1등: 6개 번호 일치 / 2,000,000,000원
    - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
    - 3등: 5개 번호 일치 / 1,500,000원
    - 4등: 4개 번호 일치 / 50,000원
    - 5등: 3개 번호 일치 / 5,000원




- 발행한 로또 수량 및 번호 출력 기능
    - 로또 번호는 오름차순으로 정렬
```
8개를 구매했습니다.
[8, 21, 23, 41, 42, 43] 
[3, 5, 11, 16, 32, 38] 
[7, 11, 16, 35, 36, 44] 
[1, 8, 11, 31, 41, 42] 
[13, 14, 16, 38, 42, 45] 
[7, 11, 30, 40, 42, 43] 
[2, 13, 22, 32, 38, 45] 
[1, 3, 5, 14, 22, 45]//
```

- 당첨 내역 및 수익률 출력 기능
    - 수익률은 소수점 둘째 자리에서 반올림한다
    - 출력 후 게임종료
```
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개

총 수익률은 62.5%입니다.
```


- 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시키고, "[ERROR]"로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.
```
[ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.
```
